# 音乐创作软件 PRD（产品需求文档）

## 1. 产品概述
- 一款面向音乐爱好者的 AI 音乐创作平台，支持原创音乐生成、歌词改编、纯音乐创作，并设有歌曲广场供用户分享与二次创作。配备独立管理后台。
- 目标用户：音乐爱好者、内容创作者、短视频制作者。产品价值：降低音乐创作门槛，让普通人也能创作原创音乐并保护用户隐私。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册/登录方式 | 核心权限 |
|------|---------------|----------|
| 普通用户 | 微信 / 手机号 | 创作音乐、分享到广场、浏览广场、二次创作、提交建议 |
| 管理员 | 账号密码 | 查看用户（脱敏）、查看建议、暂停/恢复软件、查看并编辑前端代码 |

### 2.2 功能模块
1. **编辑歌曲页（主页面·最左）**：新手引导弹窗流程、需求输入框、MP3 拖拽改编区、创作模式选择、进度条、完成弹窗、广场分享弹窗
2. **歌曲广场页（中间）**：广场歌曲列表、试听播放、二次创作入口（基于他人歌曲改编）
3. **个人中心页（最右）**：微信/手机号登录、我的创作列表、建议反馈
4. **管理后台页（独立入口）**：用户管理（脱敏显示）、建议查看、暂停软件按钮、代码查看与编辑弹窗

## 3. 核心流程

### 3.1 新手引导流程
用户首次打开应用 → 弹窗"你会使用吗？"（会 / 不会）
- 点"会" → 关闭弹窗，进入主页
- 点"不会" → 弹出详细文字教程（分步骤，含图文） → 弹窗"会了吗？"（会了 / 我还是不会）
  - 点"会了" → 关闭弹窗，进入主页
  - 点"我还是不会" → 弹出视频教程弹窗（更详细流程演示）→ 关闭后进入主页

### 3.2 音乐创作流程
选择模式（原创/歌词生成/纯音乐）→ 输入需求或歌词（歌词模式选人声）→ 或拖入 MP3 改编 → 点击制作 → 进度条推进 → 完成弹窗"音乐制作完成"→ 选择下载/转发微信 → 弹窗"是否放到歌曲广场"（放/不放）

### 3.3 广场二次创作流程
浏览歌曲广场 → 试听 → 点击改编 → 跳转编辑页载入素材 → 进入创作流程

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：白色（#FFFFFF）为主，纸感米白（#FAFAF7）作衬底，营造干净编辑器质感
- **强调色**：暖珊瑚红（#FF4D2E）作为音乐能量色，用于主操作按钮与关键交互；墨黑（#1A1A1A）用于正文
- **辅助色**：深森林绿（#1F3A2E）用于次要标签；暖灰（#E8E6E1）用于分隔线与卡片描边
- **按钮风格**：主按钮实心珊瑚红圆角胶囊；次按钮白底黑边描边；危险按钮（暂停软件）实心警示红（#E11D2A）带轻微凸起
- **字体**：标题用 Fraunces（可变光学衬线，带音乐杂志气质）；正文用 Manrope（几何无衬线，清爽易读）
- **布局风格**：左侧固定竖向导航栏（三大页 Tab），主区域卡片式编辑器布局；管理后台为独立双栏布局
- **图标风格**：线性极简图标，圆角端点，与字体气质一致

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 编辑歌曲页 | 左侧导航 | 竖向三 Tab（编辑/广场/我的），珊瑚红激活指示条 |
| 编辑歌曲页 | 模式切换 | 顶部三段式分段控件（原创/歌词生成/纯音乐） |
| 编辑歌曲页 | 需求输入 | 大号多行文本框，占位提示"描述你想要的音乐…" |
| 编辑歌曲页 | MP3 拖拽区 | 正方形虚线边框拖拽区，拖入后显示文件名与波形缩略 |
| 编辑歌曲页 | 人声选择 | 歌词模式下出现男声/女声胶囊切换 |
| 编辑歌曲页 | 制作进度 | 珊瑚红渐变进度条 + 百分比 + 动态波形动画 |
| 歌曲广场页 | 歌曲卡片 | 网格卡片：封面、歌名、作者、播放/改编按钮 |
| 个人中心页 | 登录卡 | 居中卡片，微信绿按钮 + 手机号输入与验证码 |
| 管理后台页 | 危险按钮 | 右上角实心红按钮"暂停软件"带脉冲提示 |
| 管理后台页 | 代码弹窗 | 全屏弹窗左侧文件树 + 右侧代码编辑器 |

### 4.3 响应式
- 桌面优先设计，最小宽度 1024px 完整体验
- 平板（768-1024px）导航折叠为底部 Tab
- 移动端（<768px）单栏堆叠，拖拽区适配触控

### 4.4 隐私保护设计
- 手机号全程脱敏显示（138****1234），仅本人登录后可见完整号
- 微信昵称显示，不展示原始 openid
- 管理后台仅展示脱敏数据，不存储明文敏感信息
- 建议提交匿名化，不强制关联真实身份

## 5. 数据保护要求（最高优先级）
- 所有用户个人信息（手机号、微信授权信息）在数据库中加密存储
- 管理后台展示一律脱敏
- 后台接口需管理员鉴权
- 暂停软件状态下普通用户接口全部返回维护状态
